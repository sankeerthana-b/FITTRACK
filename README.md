# 🏃 FitTrack – Fitness Tracking App

### Track. Train. Transform. 💚

FitTrack is a fitness tracking mobile application developed using **Flutter and Dart**. It helps users monitor their daily fitness progress, explore workouts, track hydration, and maintain healthy habits through a clean and user-friendly interface.

The application provides dedicated sections for Home, Activity, Workout, and Profile, allowing users to explore their fitness statistics and manage their workout experience.

---

## ✨ Features

- 🏠 **Dashboard:** View daily fitness statistics and progress.
- 👣 **Step Tracking:** Monitor step counts and daily step goals.
- 🔥 **Calorie Monitoring:** View daily and weekly calorie statistics.
- 📍 **Distance Tracking:** View fitness distance statistics.
- ⏱️ **Workout Timer:** Start, pause, and reset workout timers.
- 🏋️ **Multiple Workouts:** Explore running, walking, cycling, yoga, strength training, and cardio.
- 💧 **Water Intake Tracker:** Track daily water intake with an interactive counter.
- 📊 **Activity Summary:** View weekly activity charts and fitness goals.
- 🏆 **Achievements:** Explore fitness milestones and streaks.
- 🌙 **Dark Mode:** Switch between light and dark themes.
- 🔔 **Workout Reminders:** Enable or disable the workout reminder setting.
- 👤 **User Profile:** View fitness goals and profile information.
- ❓ **Help & Support:** Access basic instructions for using the app.

## 🚀 Getting Started

### Prerequisites

To run the project locally, install:

- Flutter SDK
- Dart SDK (included with Flutter)
- Android Studio or Visual Studio Code
- An Android emulator or a physical Android device

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/FitTrack.git
```

**2. Navigate to the project directory**

```bash
cd FitTrack
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application**

```bash
flutter run
```

Replace `YOUR-USERNAME/FitTrack` with your actual GitHub repository path.
